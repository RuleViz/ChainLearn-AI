# ChainLearn AI - 专家选择器和专家集成开发计划

## 项目概述
扩展ChainLearn AI系统，添加多专家系统和智能专家选择功能，使不同学习主题能匹配最适合的专家风格进行教学。

## 核心目标
1. 创建5+个不同领域的内置专家
2. 实现AI驱动的专家自动选择
3. 集成专家提示词到现有教学流程
4. 提供用户手动选择/覆盖功能
5. 保持向后兼容性

## 整体架构变化

```
原流程: 用户主题 → AI生成计划 → 链式学习
新流程: 用户主题 → AI选择专家 → 专家确认 → 专家风格计划生成 → 专家风格链式学习
```

## 阶段一：基础架构准备（预计2-3天）

### 1.1 数据类型扩展
- 扩展`types.ts`添加专家相关类型
- 创建`ExpertProfile`、`ExpertDomain`、`SelectedExpert`接口
- 更新`WorkflowState`包含专家选择状态

### 1.2 内置专家库创建
- 创建`src/experts.ts`定义5个核心专家：
  - 科学专家（物理/数学）
  - 技术专家（编程/工程）
  - 人文专家（历史/哲学）
  - 商业专家（管理/金融）
  - 通用专家（全能型）
- 每个专家包含：ID、名称、头衔、描述、领域、提示词模板、风格特征

### 1.3 状态管理扩展
- 在App.tsx中添加`selectedExpert`和`isSelectingExpert`状态
- 更新初始状态和重置逻辑

## 阶段二：专家选择服务实现（预计3-4天）

### 2.1 专家选择AI服务
- 创建`services/expertService.ts`
- 实现`selectExpertForTopic()`函数：
  - 输入：用户主题、AI配置
  - 输出：选择的专家+置信度+理由
- 设计AI提示词用于专家匹配：
  ```prompt
  基于主题"{topic}"，从以下专家中选择最合适的：
  [专家列表...]
  考虑因素：领域匹配度、教学风格、主题复杂性
  返回JSON格式：{selectedExpertId, confidence, reasoning}
  ```

### 2.2 双提供商支持
- Gemini路径：使用结构化响应
- OpenAI兼容路径：使用JSON模式/解析
- 错误处理：降级到通用专家

### 2.3 置信度计算和备选方案
- 实现置信度阈值（>0.7为高置信度）
- 提供2-3个备选专家
- 允许低置信度时请求用户选择

## 阶段三：工作流集成（预计2-3天）

### 3.1 修改现有AI服务
- 更新`generateLearningPlan()`：注入专家提示词
- 更新`initializeNodeChat()`：使用专家教学风格
- 更新`sendChatMessage()`：保持专家一致性
- 更新`summarizeNodeChat()`：专家风格总结

### 3.2 提示词模板系统
- 创建提示词插值函数：`{TOPIC}` → 实际主题
- 专家提示词 + 基础提示词 = 完整系统指令
- 支持动态调整教学深度和风格

### 3.3 上下文传递增强

- 确保节点间专家风格一致性
- 专家变更时的平滑过渡

## 技术难点和解决方案

### 难点1：专家匹配准确性
- **解决方案**：多维度匹配算法（领域关键词、主题复杂度、用户历史）
- **备选**：用户反馈循环优化匹配模型

### 难点2：提示词冲突和组合
- **解决方案**：分层提示词系统（专家层+任务层+上下文层）
- **备选**：专家提示词优先级和覆盖规则

### 难点3：向后兼容性
- **解决方案**：默认使用通用专家作为fallback
- **备选**：专家选择可关闭，回退原始模式

### 难点4：多专家风格一致性
- **解决方案**：专家风格标识贯穿整个对话链
- **备选**：节点间风格检查验证机制

## 成功指标

- 学习完成率提升 > 15%
- 用户留存率提升 > 10%
- 专家反馈收集 > 100条

- 自定义专家创建数 > 50
- 专家库扩展至10+领域
- 专家匹配算法准确率 > 85%
- 成为核心差异化功能

## 风险管理和缓解措施

### 风险1：专家选择延迟影响用户体验
- **缓解**：实现加载状态优化，并行处理
- **备选**：缓存常见主题的专家匹配结果

### 风险2：专家风格影响学习效果
- **缓解**：提供A/B测试，收集数据优化
- **备选**：允许学习中途切换专家

### 风险3：AI提供商限制和成本
- **缓解**：优化提示词减少token使用
- **备选**：实现本地专家匹配算法（简化版）

### 风险4：功能复杂性增加
- **缓解**：渐进式发布，先核心功能后扩展
- **备选**：提供"简单模式"隐藏高级功能

## 部署计划

### 阶段部署（推荐）

## 总结

专家系统的引入将使ChainLearn AI从通用学习平台升级为个性化智能教学系统。通过匹配最适合的专家风格，不同领域的学习者都能获得更高质量、更贴合需求的教学体验。这个功能有潜力成为产品的核心竞争优势，显著提升用户满意度和留存率。

**预计总开发时间**：4-6周（含测试和优化）
**优先级**：高 - 差异化核心功能
**ROI预期**：用户参与度提升20-30%，留存率提升10-15%
